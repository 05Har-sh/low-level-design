# Low-Level Design in Java

A collection of **Low-Level Design (LLD) practice projects implemented in Java**.

This repository is focused on learning and applying object-oriented design principles through hands-on projects, with an emphasis on **clean code, SOLID principles, design patterns, and maintainable software design**.

## 📚 Projects

| Project | Concepts |
|---|---|
| [Document Editor](./document-editor) | OOP, Composition, Interfaces, SOLID, Strategy Pattern |

> More LLD projects will be added as I progress.

## 🎯 What I'm Practicing

- Object-Oriented Programming (OOP)
- SOLID Principles
- Design Patterns
- UML & Class Diagrams
- Composition over Inheritance
- Encapsulation and Abstraction
- Dependency Inversion
- Separation of Concerns
- Writing clean and maintainable Java code
- Designing extensible systems
